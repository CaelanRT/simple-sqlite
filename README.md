# Simple SQLite

I've decided in my infinite wisdom that I need to get back to my programming roots. I've been writing web applications almost exclusively for over a year now, and want to get back to some of the more systems oriented programming that I was taking in my previous school program. I also wanted to help scratch the coding by hand itch and really dig in to things technically in order to become more fluent in the basics of how computers and programs run.

One of the big things that I've learned about this year is databases, and how to interact and properly use them in my applications. Databases are behemoths, but they truly are a black box for most developers. I want to try my hand at learning how a database really works, so that I can maybe work for a database company one day (shoutout turbopuffer if you read this!). I thought, why not, let's try and scratch the hand coding itch and the deep technical learning itch in one and build a databse from scratch.

Now, am I doing it fully from scratch? No. Absolutely not. I'm not a genius like that. I'm following Connor Stack's amazing guide: https://cstack.github.io/db_tutorial/

## What I hope to gain from this
I hope to gain a better understanding of the insides of a database. I want to know how queries work, how SQL is parsed, what the hell a B-Tree is, and also want to just get better at building software. I haven't built in C in a while, and I want to get back to my roots and really be elbows deep in the code. This will probably not become a huge project (I hope not atleast), but if by the end of it I can have a working SQLite copy with which I completely understand, and can maybe try and extend it with one feature by myself, that's a success in my book.
